# Stellarweb Smart Contracts

This folder contains Soroban smart contract interaction code and documentation.

## Structure

- **src/soroban/** - Soroban contract interaction SDK modules
  - Contract deployment
  - Contract invocation
  - Contract reading
  - Event handling
  - Simulation
  - State management

## Documentation

- **docs/** - Contract-related documentation and recipes

## Key Features

- Contract deployment with validation
- Contract interaction builder
- Event decoding and archival
- Contract state tracking
- Factory statistics
- Multi-signature contract execution
- NFT metadata handling
- Storage management

Refer to individual module documentation for detailed usage.
